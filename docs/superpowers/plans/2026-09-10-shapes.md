# Shapes, effects and motion — implementation plan

**Goal:** Add a `shape` node kind (rect, circle, line, polygon presets, and sanitised custom SVG imports) that can be placed from the Insert panel, scaled, filled and stroked from the inspector, and given colour effects and a preset animation. Effects and motion apply to every node kind.

**Spec:** `docs/superpowers/specs/2026-09-10-shapes-design.md` — read it first. It has the type definitions, defaults, sanitiser rules, preset table and test list.

**Tech:** TypeScript strict, React 18 peer, tsup, `node:test` unit tests against `dist/`, Playwright e2e against `example/`.

## Global constraints

- **`DOCUMENT_VERSION` does not move.** Every addition is optional.
- **Never trust the document.** Custom SVG markup is sanitised at import *and* at render. `parseShape` refuses anything malformed. A shape that fails to parse at render draws nothing and never throws.
- **Keyframes are a closed set.** No user-authored keyframes, ever.
- **No CSS files, no runtime dependencies, no `!important` for an override** — the single exception is the reduced-motion rule in the spec.
- **Never import from `editor/` in `core/`, `components/` or `runtime/`.**
- **Unit tests import from `../dist/index.js` or `../dist/internal.js`**, so anything under test must be exported from `src/index.ts` (supported) or `src/internal.ts` (internals). `npm run test:unit` builds first.
- **Style:** no semicolons, single quotes, 2-space indent, comments explain *why* in the voice of the surrounding files. Match neighbouring code exactly.
- **Verify before claiming done:** `npm run typecheck && npm test` for unit work; the e2e suite (`npm run test:e2e`) for editor work. Paste real output.

### A2. Sanitiser

`src/runtime/sanitize.ts` — add:

```ts
export interface SanitizedSvg { svg: string; viewBox: string }
export interface SanitizeSvgOptions {
  /** Prefix for every id and reference, so two imports on one page don't share a gradient. */
  scope?: string
}
export const SVG_LIMIT = 64 * 1024
/** Returns the sanitised inner markup and the root viewBox, or null when there is no usable <svg>. */
export function sanitizeSvg(markup: string, options?: SanitizeSvgOptions): SanitizedSvg | null
```

Rules are in the spec ("Sanitising an import"). Notes:
- Browser path: parse with `new DOMParser().parseFromString(markup, 'image/svg+xml')`; a `parsererror` document returns null. Walk the root's descendants with the allow-list; remove disallowed elements with their subtree. Return `root.innerHTML` and the root's `viewBox` (fall back to `0 0 ${width} ${height}` from the root's `width`/`height` when numeric, else `0 0 100 100`).
- Scoping: collect ids first, then rewrite `id`, `href`, `xlink:href` and any attribute value containing `url(#id)`. Scope string is sanitised to `[a-zA-Z0-9_-]` before use.
- Server path (`typeof DOMParser === 'undefined'`): regex-strip `<script|style|foreignObject|image|a|animate\w*|set|iframe>` blocks and self-closing forms, `on\w+=` attributes, `href` values not starting with `#`, `javascript:`. Extract viewBox and inner markup from the outer `<svg …>…</svg>` with a regex. Document that the browser pass is the authoritative one.
- Refuse (return null) when the sanitised inner markup exceeds `SVG_LIMIT`.
- Export `sanitizeSvg`, `SVG_LIMIT` from `src/internal.ts`.

### A3. Shape runtime

`src/runtime/shape.ts` (new):

```ts
export const SHAPE_PRESETS: Record<ShapePreset, ShapeSpec>
export function parseShape(value: unknown): ShapeSpec | null
/** The style an inserted shape starts with. */
export function shapeStyleDefaults(shape: ShapeSpec): StyleMap
/** Geometry for the preset shapes, as attribute bags per child element. */
export function shapeElements(shape: Exclude<ShapeSpec, { type: 'custom' }>): Array<{ tag: 'rect' | 'ellipse' | 'line' | 'polygon'; attrs: Record<string, string> }>
```

- Presets: `rect` `{ type:'rect' }`; `circle`; `line` `{ x1:0,y1:50,x2:100,y2:50 }`; `triangle` points `[[50,0],[100,100],[0,100]]`; `star` a five-point star inscribed in the box; `hexagon` a regular hexagon.
- `parseShape` is the untrusted parser: finite numbers only, `rx` clamped 0–50, polygon points 3–256 pairs of finite numbers, custom `svg` a string that passes `sanitizeSvg` (unscoped) and `viewBox` a string matching `/^-?[\d.]+( -?[\d.]+){3}$/` (else taken from the sanitiser). Returns a fresh, normalised object, never the input.
- `shapeElements`: rect → `{ tag:'rect', attrs:{ x:'0', y:'0', width:'100', height:'100', rx } }`; circle → `ellipse cx=50 cy=50 rx=50 ry=50`; line → `line`; polygon → `polygon points="x,y x,y…"`. Every element gets `pathLength: '1'` and `vector-effect: 'non-scaling-stroke'`.
- `shapeStyleDefaults` per the spec's defaults table.
- Export `SHAPE_PRESETS`, `parseShape`, `shapeStyleDefaults` from `src/index.ts` (they are the supported way to build a shape without the editor); `shapeElements` from `src/internal.ts`.

### A4. Operations, migrate, layers, store

`src/core/operations.ts`:
- `insert-node` gains `shape?: ShapeSpec`. When `kind === 'shape'`: `parseShape(operation.shape)` must succeed or `fail('`shape` is required when kind is `shape`')` / `fail('`shape` is not a valid shape')`. - `INSERTED_KINDS` gains `'shape'`.
- `describeDocument`: push `'shape'` into `overrides` when `override.shape` is set.
- Update the `VeditOperation` doc comment list.

`src/core/migrate.ts` — `normalizeInserted` kinds gain `'shape'`. Add a `migrate.test.mjs` case: a stored shape node survives `migrateDocument` with its override intact.

`src/core/layers.ts` — `pruneOverride`: `if (next.shape === undefined) delete next.shape`.

`src/core/store.ts` — `insert(parentId, kind, options: { component?, index?, shape? })` passes `shape` through to the operation.

### A5. Rendering

`src/components/Shape.tsx` (new) — `ShapeView({ node })`:
- Reads the override with `useVeditState((s) => s.doc.nodes[node.id]?.shape)`, runs it through `parseShape`. `null` → render `<Editable id as="svg" kind="shape" label="Shape" viewBox="0 0 100 100" />` (an empty, still-selectable svg) so a broken shape can be found and deleted.
- Preset: `<Editable id={node.id} as="svg" kind="shape" label={labelFor(shape)} viewBox="0 0 100 100" preserveAspectRatio="none" xmlns="http://www.w3.org/2000/svg">{shapeElements(shape).map(el => createElement(el.tag, { key, ...el.attrs }))}</Editable>`. Attribute names in `shapeElements` must be what React wants for SVG (`vectorEffect`, `pathLength`) — decide one convention and document it.
- Custom: `useMemo(() => sanitizeSvg(shape.svg, { scope: node.id }), [shape.svg, node.id])`, then `<Editable … viewBox={shape.viewBox} preserveAspectRatio="xMidYMid meet" dangerouslySetInnerHTML={{ __html: sanitized?.svg ?? '' }} />`. `Editable` already short-circuits children when `dangerouslySetInnerHTML` is set — confirm by reading `EditableNode`, and note that `override.html` is *not* how this is passed (that would run `sanitizeHtml`, which strips every SVG tag).
- Labels: "Rectangle", "Circle", "Line", "Polygon", "Shape" (custom).

`src/components/Editable.tsx` — `InsertedView`: `case 'shape': return <ShapeView node={node} />`. `defaultTagFor('shape')` → `'svg'`. `isVoidElement` unchanged.

Check `useEditable`'s `ref` type: it is `(element: HTMLElement | null) => void`; an `<svg>` gives an `SVGSVGElement`. Both have `getBoundingClientRect`, `closest`, `parentElement`, `style`, `getAttribute`. If TypeScript complains at the `as="svg"` call site, widen `ref`'s parameter to `Element | null` in `useEditable` and the `RegisteredNode.element` type to `HTMLElement | SVGSVGElement` **only if** it is a one-line-each change; otherwise cast at the call site and leave a comment. Do not refactor the registry.

## Wave 1 · Agent B — effects and motion runtime

### B1. Filter

`src/runtime/filter.ts` (new), modelled on `src/runtime/transform.ts`:

```ts
export interface FilterParts { blur: number; brightness: number; contrast: number; saturate: number; hueRotate: number; grayscale: number; dropShadow?: string }
export const FILTER_IDENTITY: FilterParts
export function parseFilter(value: string | number | undefined): FilterParts
export function serializeFilter(parts: FilterParts): string | undefined   // undefined when identity
export function withFilter(current: string | number | undefined, patch: Partial<FilterParts>): string | undefined
```

Units: `blur(Npx)`, `brightness(N)`, `contrast(N)`, `saturate(N)`, `hue-rotate(Ndeg)`, `grayscale(N)`, `drop-shadow(<string>)`. Round to 3 dp like `transform.ts`. Unknown functions in an existing value are preserved verbatim in order (store them in a `rest: string[]` field if needed — decide and document).

### B2. Animation

`src/runtime/animation.ts` (new):

```ts
export type AnimationPreset = 'spin' | 'pulse' | 'float' | 'fadeIn' | 'draw' | 'wiggle'
export const ANIMATION_PRESETS: Record<AnimationPreset, { label: string; keyframes: string; duration: number; easing: string; loops: boolean }>
export interface AnimationParts { preset: AnimationPreset; duration: number /* ms */; easing: string; loops: boolean }
export function animationName(preset: AnimationPreset): string        // `vedit-${preset}`
export function parseAnimation(value: string | number | undefined): AnimationParts | null
export function serializeAnimation(parts: AnimationParts): string       // `vedit-spin 2000ms linear infinite`
export function presetsIn(css: string): AnimationPreset[]               // which vedit-* names a declaration string references
export function keyframesFor(presets: Iterable<AnimationPreset>): string
export const REDUCED_MOTION_RULE: string
```

- Keyframes bodies per the spec table. `draw` keyframes set `stroke-dasharray:1` in its `from` frame as well as animating `stroke-dashoffset` 1 → 0, so it works without the user also setting the dasharray.
- `parseAnimation` accepts the serialised form and reasonable variants (`2s` as well as `2000ms`, `infinite` or a count); returns null for anything not naming a `vedit-*` preset.
- Add `'animationIterationCount'` to `UNITLESS` in `css.ts` if numbers can reach it.

### B3. CSS emitter

`src/runtime/css.ts` — in `documentToCss`, collect the presets referenced by every emitted declaration block (scan the `animation` and `animationName` values of each `StyleMap` as it is emitted — do not regex the final CSS). When the set is non-empty, prepend `keyframesFor(set)` and append `REDUCED_MOTION_RULE`. When empty, output is byte-identical to today — assert this in a test against an existing fixture.

Keyframes names go through the same `CSS_BREAKOUT` discipline as everything else; the bodies are constants so they need no escaping, but say so in a comment.
